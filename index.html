Run the project

Use a PHP-enabled web server from this folder. For the built-in server, open a terminal here and run:

php -S localhost:8000

Then visit http://localhost:8000. For XAMPP, copy this folder into htdocs and open http://localhost/labs-4-to-12/. See README.md for setup details.
